Decision Discipline

Automation should be predictable before it is powerful.

This concept leads with architecture maturity: the viewer immediately sees that remediation is bounded by context, exception state, production sensitivity, and audit requirements.

Critical finding, owner resolved, approved control Auto-remediate and write evidence.
Missing owner or incomplete account metadata Notify security queue and log missing context.
Exception tag or sensitive production resource Skip automatic action and route for review.

Architecture Principles

Senior-level cloud security design habits.

Least privilege

Remediation roles expose only the APIs needed for approved changes.

Fail closed

Unknown metadata, exceptions, or unsupported resources stop automation.

Evidence first

Every automated decision produces a record that can be reviewed later.
