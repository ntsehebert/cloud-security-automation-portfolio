Architecture Principles

How I design cloud security automation

Least privilege by default

Automation roles should expose only the APIs needed for approved actions, with scoped trust and traceable sessions.

Automate the repeatable work

High-confidence, well-bounded findings can move fast; ambiguous or high-risk findings should route with context.

Evidence before action

Each workflow should preserve the finding, decision inputs, action taken, result, and failure reason.

Fail closed when context is missing

Missing owner, unknown environment, exception state, or unsupported resource type should stop remediation and trigger review.
